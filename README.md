# 📐 Mathematical Statements Application

This is a simple web app I made to explore and visualize logical operations like **AND**, **OR**, **NOT**, **IF...THEN**, and **IF AND ONLY IF**. It also generates complete truth tables to help understand how these operations behave with different inputs.

---

## 🔹 Features

### ✅ Logical Input
- Choose boolean values (True/False) for **A** and **B**
- Instantly see the result for each logical operation

### 📊 Truth Table Generator
- Generates a full truth table for all combinations of A and B
- Includes:
  - **AND** (A ∧ B)
  - **OR** (A ∨ B)
  - **NOT** (¬A, ¬B)
  - **IF...THEN** (A → B)
  - **IF AND ONLY IF** (A ↔ B)

---

## 💻 How to Run

1. Clone or download this repository
2. Open the `index.html` file in any modern browser
3. Interact with the interface to test logical operations
